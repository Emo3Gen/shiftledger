# COWORK_CONTEXT — ShiftLedger

## Проект
ShiftLedger — система управления сменами и расчёта зарплат для детского центра «Про Дети».
Telegram-бот + веб-панель директора. Сотрудники пишут доступность в чат, движок автоматически собирает расписание.

## Стек
- Node.js 18+ / Express 5
- PostgreSQL (Supabase) + Prisma
- React + Vite (Chat Simulator)
- Telegram Bot (grammY)
- Jest (тесты)

## Ключевые модули
| Модуль | Файл | Назначение |
|--------|------|------------|
| Парсер фактов | `backend/factsParserV0.js` | Извлечение структурированных фактов из сообщений (regex, без LLM) |
| Движок расписания | `backend/scheduleEngineV0.js` | Автоматическое построение графика смен из фактов |
| Справочник сотрудников | `backend/userDirectory.js` | Роли, минимальные часы, уровни навыков |
| Табель | `backend/timesheetV0.js` | Расчёт зарплат: часы + уборки + доп.занятия |
| Telegram-бот | `backend/telegram/` | Приём сообщений, команды `/schedule`, `/pay`, `/as` |
| Симулятор | `apps/simulator/` | 3-колоночный отладочный UI |

- **Семён** — владелец проекта, координатор. Получает отчёты на понятном языке, без кода.
- **Агент 1** — фикс багов, диагностика ядра (scheduleEngine, factsParser)
- **Агент 2** — фронтенд и интеграции (симулятор, Telegram-бот)

## Известные проблемы
1. **Баг противоречий в расписании** (SL-001): движок может назначить сотрудника на смену, для которой у него есть факт SHIFT_UNAVAILABILITY, если UNAVAILABILITY пришла после AVAILABILITY, но до SHIFT_ASSIGNMENT. Проверка `unavailableBySlot` в фазе ребаланса (Phase 2.5) не выполняется.
2. **Нет стресс-тестов** (SL-005): текущие тесты покрывают happy path, но нет сценариев с экстремальными данными.
