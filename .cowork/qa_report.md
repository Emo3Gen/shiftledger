### SL-001 — Баг противоречий в расписании (ЗАКРЫТ ✅)
**Серьёзность:** высокая
**Описание:** При ребалансе минимальных часов (Phase 2.5 в `scheduleEngineV0.js`) движок не проверял список недоступных сотрудников (`unavailableBySlot`). Если сотрудник отмечал недоступность на слот, но при ребалансе был выбран как кандидат — он мог получить назначение вопреки своей недоступности.

**Исправление:** Добавлена проверка `unavailableBySlot` в цикл Phase 2.5 перед назначением:
```javascript
const unavailForSlot = unavailableBySlot.get(slot.slotKey);
if (unavailForSlot && unavailForSlot.has(empId)) continue;
```

**Новый тест:** `rebalance does not assign unavailable user to slot` — проходит ✅
